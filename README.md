# Portfolio

A personal portfolio project developed as part of **FlyRank Front-end AI internship** project.

## Technology Stack

| Technology             | Purpose                                           |
| ---------------------- | ------------------------------------------------- |
| **React**              | User interface development                        |
| **Vite**               | Development server and build tool                 |
| **JavaScript**         | Application logic                                 |
| **HTML**               | Semantic document structure                       |
| **CSS**                | Styling and responsive design                     |
| **React Three Fiber**  | React-based 3D experiences and interactive scenes |
| **Three.js**           | 3D rendering and graphics capabilities            |
| **Git**                | Version control                                   |
| **GitHub**             | Repository management                             |
| **Visual Studio Code** | Development environment                           |
| **Claude Code**        | AI-assisted development                           |

> **3D technologies are used selectively as an enhancement to the portfolio rather than as a requirement for every section.**
